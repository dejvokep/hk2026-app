# TatraShare

An AI-powered expense-sharing and savings platform built on EU PSD2 open banking. The app lets users manage shared virtual fiscal accounts, distributing funds from contributors to vendors, with intelligent automation throughout. Built in a team at HackKošice 2026, where it won the Tatra Banka (Raiffeisen Group) challenge and an MLH award for innovative use of MongoDB.

Created for [HackKošice 2026](https://hackkosice.com/), where it won the Tatra Banka (Raiffeisen Group) challenge. See the full submission and awards on [Devpost](https://devpost.com/software/tatra-3ud79v).
